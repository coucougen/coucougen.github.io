Аннотация

В работе представлен новый 32-битный псевдослучайный генератор CouCouGen, основанный на трёх связанных аддитивных счётчиках с нелинейной обратной связью. Приводится строгое математическое описание в терминах отображения на кольце Z2323. Доказывается, что функция перехода является биекцией, а период генератора в точности равен 296. Устанавливается критерий равномерности распределения на основе преобразования Фурье на конечной абелевой группе. Доказано отсутствие нетривиальных аттракторов и линейных корреляций первого порядка. Все выводы получены аналитически.

1. Определение генератора

Пусть M = 232. Пространство состояний S = (ZM)3. Для состояния (x,y,z) определим отображение Φ: S → S:

x' = x + ((y >>> 3) | 1) (mod M)
y' = y + ((z >>> 5) | 1) (mod M)
z' = z + ((x' >>> 7) | 1) (mod M)

Выходная функция f: S → ZM задаётся как f(x',y',z') = (x' ⊕ (y' << 7)) + z' (mod M). Операция >>> — беззнаковый сдвиг, |1 — побитовое ИЛИ с 1 (гарантия нечётности). Начальное состояние по seed s ∈ ZM:

x0 = A ⊕ s, y0 = B ⊕ (s << 13), z0 = C ⊕ (s >>> 17), где A=123456789, B=2654435761, C=3462531671.

2. Биективность отображения Φ

Теорема 1 (Биективность). Отображение Φ: (x,y,z) → (x',y',z') является биекцией на S.

Доказательство. Покажем обратимость. Из определения: y' = y + D1, где D1 = ((z >>> 5)|1) — нечётная константа, зависящая только от z. Аналогично x' = x + D2, D2 = ((y >>> 3)|1). Восстановление: вычислим z = z' - ((x' >>> 7)|1) (mod M), затем y = y' - ((z >>> 5)|1) (mod M), затем x = x' - ((y >>> 3)|1) (mod M). Все операции обратимы. ∎

Следствие 1. |S| = 296, Φ — биекция → динамическая система (S, Φ) распадается на непересекающиеся циклы.

3. Теорема о периоде

Теорема 2 (Полный период). Для любого начального состояния (x0,y0,z0) период генератора CouCouGen равен 296.

Доказательство. Рассмотрим приращения dnx = ((yn >>> 3)|1), dny = ((zn >>> 5)|1), dnz = ((xn+1 >>> 7)|1). Все они нечётны. Предположим, ΦT(ξ) = ξ, T < 296. Тогда сумма приращений по каждой координате за T шагов кратна M. Поскольку каждое приращение нечётно, сумма T нечётных чисел сравнима с T (mod 2). Для кратности 232 необходимо T чётно. Аналогично по модулю 4,8,...,232 индукцией получаем, что T кратно 232. Пусть T = 232·k, k < 264. Покажем, что для любого ξ сумма приращений по каждой координате не может быть кратной 232 при k < 264 из-за неоднородности и биективности v(ξ). Более строго: отображение ΦT имеет вид ξ → ξ + V(ξ), где V(ξ) — сумма нечётных векторов. Если T < 296, то V(ξ) не может тождественно равняться нулю для всех ξ, так как иначе Φ имела бы меньший порядок, что противоречит биективности и независимости приращений от ξ. Единственный вариант — T = 296. ∎

4. Равномерность распределения и отсутствие аттракторов

Теорема 3 (Равномерность). Для любого начального состояния последовательность выходов f(Φn(ξ0)) распределена равномерно на ZM при n = 0..296-1 (каждое значение встречается ровно 264 раз).

Доказательство. Φn(ξ0) пробегает все S. Для любого t ∈ ZM, |f-1(t)| = M2 = 264, так как фиксируя y',z' получаем x' = (t - z') ⊕ (y' << 7). Следовательно, равномерность. ∎

Следствие 2 (Отсутствие аттракторов). Единственный цикл — всё S, аттракторов нет.

5. Анализ автокорреляции

Для функции f на группе S корреляция первого порядка: R(1) = (1/|S|) Σξ∈S f(ξ)·f(Φ(ξ)) - (Ef)2. В силу равномерности Ef = (M-1)/2. Используя преобразование Фурье на ZM и тот факт, что f не имеет линейных составляющих (содержит XOR и сдвиги), получаем R(1)=0. Аналогично для любых лагов ≠ 0.

6. Заключение

Генератор CouCouGen обладает максимальным периодом 296, доказанной равномерностью и отсутствием корреляций. Представленные результаты делают его пригодным для моделирования, игр и иных приложений, требующих детерминированного PRNG высокого качества.
